# KaizenHacks Typography Guidelines

## 1. Typography System

KaizenHacks uses two primary typefaces:

- **Cormorant Garamond** — expressive/display typeface
- **Space Grotesk** — functional/system typeface

The two fonts are intentionally paired to create contrast between editorial character and modern technology.

**Cormorant Garamond = personality**  
**Space Grotesk = functionality**

Do not replace either typeface casually. The pairing is part of the KaizenHacks visual identity.

---

## 2. Cormorant Garamond

### Role

Cormorant Garamond is the primary **display and expressive typeface**.

Use it when typography needs to feel distinctive, editorial, thoughtful, or memorable.

### Recommended Uses

- Major headlines
- Large section titles
- Editorial-style headings
- Campaign headlines
- Poster headlines
- Event titles when an expressive treatment is appropriate
- Pull quotes
- Important statements
- Selected brand-focused typography

### Recommended Weights

- Semibold
- Bold

Avoid relying heavily on very thin weights, especially in small sizes or low-contrast situations.

### Character

Cormorant Garamond should provide the visual personality of KaizenHacks without making the brand feel old-fashioned or overly decorative.

Use it deliberately rather than everywhere.

---

## 3. Space Grotesk

### Role

Space Grotesk is the primary **functional and supporting typeface**.

It handles information that needs to be clear, modern, structured, and easy to scan.

### Recommended Uses

- Body text
- Navigation
- Buttons
- Labels
- Dates
- Numbers
- Captions
- Forms
- UI text
- Event information
- Presentation information
- Documents
- Technical information
- Supporting headings

### Recommended Weights

- Regular
- Medium
- Semibold
- Bold

Use weight changes to establish hierarchy before introducing additional typographic styles.

### Character

Space Grotesk should keep KaizenHacks readable and contemporary while allowing Cormorant Garamond to provide the expressive character.

---

## 4. Type Hierarchy

Use a consistent hierarchy across brand materials.

| Level | Typeface | Weight | Purpose |
|---|---|---|---|
| Display / Level 1 | Cormorant Garamond | Semibold/Bold | Major headlines |
| Level 2 | Cormorant Garamond | Semibold | Section headings |
| Level 3 | Space Grotesk | Semibold | Subheadings |
| Body | Space Grotesk | Regular | Main reading text |
| Labels | Space Grotesk | Medium | Metadata and labels |
| Buttons | Space Grotesk | Semibold | Actions |
| Captions | Space Grotesk | Regular/Medium | Supporting information |

The hierarchy should remain recognizable even when exact font sizes change between formats.

---

## 5. Font Pairing Rules

### Preferred Pairing

Use Cormorant Garamond for the main expressive element and Space Grotesk for supporting information.

Example:

**Cormorant Garamond**  
Main headline

**Space Grotesk**  
Supporting explanation, date, location, or additional information.

This contrast should be intentional.

### Avoid

- Using Cormorant Garamond for entire paragraphs
- Using Space Grotesk for every piece of typography when a major headline is present
- Mixing many unrelated typefaces
- Introducing decorative fonts without a specific brand reason
- Using excessive font weights
- Creating hierarchy through random font changes

KaizenHacks should normally remain a **two-typeface system**.

---

## 6. Creating Hierarchy

Hierarchy should not depend only on font size.

Use a controlled combination of:

1. Typeface
2. Weight
3. Size
4. Line height
5. Spacing
6. Position
7. Contrast

Do not make everything large or bold to create emphasis.

A strong KaizenHacks layout should normally have one clear dominant typographic element, followed by progressively quieter information.

---

## 7. Headlines

Headlines should be concise and visually confident.

### Use

- Cormorant Garamond Semibold/Bold
- Large scale where appropriate
- Comfortable line spacing
- Strong contrast against the background
- Intentional line breaks

### Line Breaks

Do not break headlines randomly.

Prefer line breaks that preserve the meaning and rhythm of the phrase.

For example:

> Build ideas  
> that move forward

is preferable to breaking words or creating awkward grammatical divisions.

---

## 8. Body Text

Body text should prioritize readability.

Use:

- Space Grotesk Regular
- Moderate line length
- Comfortable line height
- Clear contrast
- Consistent paragraph spacing

Avoid:

- Extremely narrow text columns
- Very small body text
- Excessive letter spacing
- Long paragraphs without visual separation

For digital interfaces, readability takes priority over stylistic expression.

---

## 9. Labels, Metadata, and Small Text

Use Space Grotesk for:

- Dates
- Locations
- Categories
- Navigation
- Event metadata
- Small descriptions
- Buttons
- Status indicators

Medium or Semibold can be used for emphasis.

Small text should never depend on Cormorant Garamond for readability.

---

## 10. Capitalization

Use capitalization intentionally.

### Preferred

- Sentence case for most normal content
- Title Case selectively for formal headings or titles
- Uppercase sparingly for labels and metadata

Avoid excessive ALL CAPS.

If uppercase text is used, slightly increased letter spacing may improve readability.

---

## 11. Letter Spacing

Do not apply large tracking values by default.

### General Guidance

- Headlines: normal or slightly tight spacing
- Body text: normal spacing
- Small uppercase labels: slightly increased spacing
- Buttons: normal or slightly increased spacing when necessary

Letter spacing should support readability and hierarchy, not become a decorative effect.

---

## 12. Line Height

Use generous line height for reading text.

General starting points:

- Large headlines: approximately 0.9–1.1× font size
- Subheadings: approximately 1.1–1.3×
- Body text: approximately 1.4–1.7×
- Small labels: approximately 1.2–1.4×

These are starting points, not fixed values. Adjust based on the actual font size, medium, and layout.

---

## 13. Alignment

Default to:

- Left alignment for most content
- Center alignment for selected campaign/event compositions
- Avoid justified text unless there is a specific editorial reason

Typography should align with the overall layout grid.

Do not center-align large amounts of body text simply because the layout has empty space.

---

## 14. Responsive Typography

Typography should adapt to the medium.

### Digital

Prioritize:

- Readability
- Clear hierarchy
- Responsive sizing
- Accessible contrast
- Comfortable spacing

### Print

Prioritize:

- Physical reading distance
- Paper size
- Printing quality
- Appropriate line length
- Optical balance

### Social Media

Prioritize:

- Immediate recognition
- Large, readable headlines
- Minimal supporting text
- Strong hierarchy

The typography system remains the same even when sizes change.

---

## 15. Event Typography

Events may have their own visual personality, but they should remain connected to KaizenHacks.

Use the master typography system as the foundation:

- Cormorant Garamond for major expressive event messaging
- Space Grotesk for practical event information

Event-specific typography should not completely replace the KaizenHacks typographic identity unless the event is intentionally operating as an independent sub-brand.

---

## 16. Digital Product and UI Typography

For interfaces, Space Grotesk should generally be the dominant typeface.

Use it for:

- Navigation
- Menus
- Buttons
- Forms
- Settings
- Notifications
- Cards
- Tables
- Data
- Functional information

Cormorant Garamond may be used for major introductory or editorial moments, but should not reduce interface clarity.

---

## 17. Accessibility

Typography must remain readable across backgrounds and devices.

Always check:

- Text/background contrast
- Font size
- Line height
- Weight
- Text density
- Mobile readability

Do not use thin type against busy photography or low-contrast backgrounds.

Never sacrifice legibility for visual style.

---

## 18. Typography on Photography

When placing type over images:

1. Ensure sufficient contrast.
2. Use a controlled overlay or background treatment when necessary.
3. Avoid placing important text over visually busy areas.
4. Prefer Space Grotesk for small informational text.
5. Use Cormorant Garamond for major display text when the image composition supports it.

The image should support the typography rather than compete with it.

---

## 19. Typography and Brand Personality

KaizenHacks typography should communicate:

- Intelligence
- Confidence
- Curiosity
- Modernity
- Creativity
- Professionalism
- Openness
- Ambition

It should avoid feeling:

- Corporate and generic
- Overly futuristic
- Academic in an institutional sense
- Decorative for its own sake
- Startup-bro or hype-driven
- Childish or overly playful

The Cormorant Garamond + Space Grotesk pairing creates this balance.

---

## 20. Consistency Rules

Always:

- Use the approved typefaces.
- Maintain a clear hierarchy.
- Use Cormorant Garamond selectively.
- Use Space Grotesk for functional information.
- Keep typography aligned with the layout grid.
- Prioritize readability.
- Adjust sizing for the medium without changing the typographic system.

Avoid:

- Random font substitutions.
- Excessive font weights.
- Too many text styles.
- Decorative typography without purpose.
- Poor contrast.
- Inconsistent heading hierarchy.
- Using typography effects to compensate for weak layout.

---

## 21. Quick Reference

### Cormorant Garamond

**Purpose:** Expression and personality

Use for:

- Major headlines
- Display typography
- Editorial headings
- Pull quotes
- Campaign statements
- Selected event titles

### Space Grotesk

**Purpose:** Function and clarity

Use for:

- Body text
- UI
- Navigation
- Buttons
- Labels
- Metadata
- Dates
- Captions
- Documents
- Technical information

### Core Rule

**Cormorant Garamond attracts attention.  
Space Grotesk communicates information.**

Together they form the core KaizenHacks typography system.
